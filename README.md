# AI Design, Branding & Marketing Studio Workspace

## Execution Setup
1. Run the targeted automated environment launcher script inside `/scripts` matching your workstation OS.
2. The installation scripts look for python virtual environments, automatically upgrades installation toolings, hooks down project configurations, and starts both components.
3. Access Frontend portal via: `http://localhost:3000`
4. Access Backend Documentation portal via: `http://localhost:8000/docs`
